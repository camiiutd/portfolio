Toronto Maple Leafs LINE MAKER

[GRAPH 1] Line maker overview.

This time, I built an interactive line maker for the current Toronto Maple Leafs roster. I used a great API for this project. Shout out to the maintainers for such a well-documented resource!

First, I learned how to normalize the JSON data from the API, which involved carefully assigning the correct data types. Then, I started building the line selection buttons and the rink layout.

Beyond basic visuals, I implemented advanced business logic using DAX. Then, developed dynamic measures to calculate an overall line rating by weighting offensive performance and goaltending efficiency, as well as weighted averages for goalie statistics.

[GRAPH 2] Line stats screenshot.

The following dashboards were designed to resemble real scouting tools. You can navigate between a tactical board and individual player profiles through synchronized slicers. I also included scatter plots to distinguish high-efficiency shooters from playmakers and built player profiles that compare season totals with per-game averages, providing a more complete view of performance.
